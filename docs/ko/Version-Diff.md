# 버전 비교

버전 비교 페이지를 사용하면 두 스캔 결과를 나란히 비교하여 버전 간에 어떤 컴포넌트가 추가, 제거, 업데이트되었거나 새로운 위협이 되었는지 확인할 수 있습니다.

URL: `/projects/{id}/version-diff`

---

## 사용 방법

1. 프로젝트를 열고 **버전 비교**로 이동합니다.
2. 페이지가 가장 최근의 완료된 스캔 두 개를 자동으로 선택합니다 — 왼쪽에는 이전 스캔(**From**), 오른쪽에는 새 스캔(**To**).
3. 다른 쌍을 비교하려면 드롭다운에서 다른 스캔을 선택합니다. 각 항목에는 버전 라벨과 스캔 날짜가 표시됩니다.

선택을 바꾸면 비교 결과가 즉시 갱신됩니다 — 별도의 비교 버튼은 없습니다. 완료된 스캔만 목록에 표시되며, 버전 라벨이 없는 스캔은 스캔 날짜로 표시됩니다.

상단의 요약 카드에는 **추가됨**, **제거됨**, **업데이트됨**, **새로운 위협** 카테고리별 개수와 전체 변경 개수가 표시됩니다.

---

## AI 비교 인사이트

AI가 활성화되어 있으면 테이블 위에 비교 결과에 대한 한 줄 AI 요약이 표시됩니다.

OsWL은 스캔 후 AI 인리치먼트 과정에서 버전 비교 인사이트를 하나의 통합 AI 인사이트 호출(보안 포스처 및 추세 인사이트와 함께)로 생성하여 스캔에 저장합니다. 저장된 인사이트가 생성될 때 사용된 것과 동일한 기준 스캔과 비교하면 페이지는 저장된 인사이트를 재사용하고, 그 외의 조합에서는 요청 시 생성합니다. AI가 비활성화되어 있거나 호출이 실패하면 인사이트는 표시되지 않습니다.

---

## 비교 섹션

필터 탭(**전체** / **추가됨** / **제거됨** / **업데이트됨** / **새로운 위협**)으로 목록을 좁힐 수 있습니다. 각 행은 왼쪽에 **From** 스캔, 오른쪽에 **To** 스캔을 보여주며, 양쪽에 컴포넌트 이름, 버전, 리스크 배지(가장 높은 알려진 심각도)가 표시되고 오른쪽 끝에 변경 유형 태그가 붙습니다.

### 추가된 컴포넌트

**To** 스캔에는 있지만 From 스캔에는 **없는** 컴포넌트로, 알려진 취약점이 없는 항목.

두 버전 사이에 추가된 새 의존성입니다. 이미 알려진 CVE가 있는 상태로 추가된 컴포넌트는 대신 **새로운 위협**으로 분류됩니다 — 새로운 공격 표면이므로 먼저 확인하세요.

### 제거된 컴포넌트

**From** 스캔에는 있지만 To 스캔에는 **없는** 컴포넌트.

제거된 의존성입니다. 알려진 CVE가 있는 항목의 제거는 긍정적인 신호입니다.

### 업데이트된 컴포넌트

**두 스캔 모두**에 있지만 **다른 버전**이며, 심각도가 상승하지 않은 컴포넌트.

### 새로운 위협

두 스캔 사이에 리스크가 커진 컴포넌트:

* 이미 알려진 취약점을 가진 채 새로 추가된 컴포넌트,
* 최고 심각도가 상승한 버전 업데이트,
* 동일한 버전인데 평가된 심각도가 상승한 컴포넌트(예: 기준 스캔 이후에 CVE가 공개된 경우).

> 하나의 스캔 안에 **같은 라이브러리가 여러 버전으로 존재**하는 경우(다이아몬드 의존성 — 예: 두 개의 전이 경로가 서로 다른 메이저 버전을 끌어오는 경우), 각 버전은 하나의 행으로 뭉뚱그려지지 않고 개별적으로 추적·비교됩니다.

## 활용 사례

* **릴리즈 전 검토**: 릴리즈 후보를 마지막 릴리즈와 비교하여 새로운 고심각도 CVE가 도입되지 않았는지 확인.
* **의존성 감사**: 두 기능 브랜치를 비교하여 PR의 의존성 변경에 따른 리스크 영향 파악.
* **수정 검증**: 특정 라이브러리 업그레이드가 예상된 CVE를 실제로 해결했는지 확인.
* **회귀 감지**: 의존성 해결 충돌로 인한 의도치 않은 버전 다운그레이드 식별.

---

## 팁

* 비교는 저장된 스캔 데이터에서 요청 시 계산됩니다 — 재스캔이 필요 없습니다.
* 두 스캔의 컴포넌트 목록이 동일하고 유의미한 변경이 없으면 **변경 사항 없음**이 표시됩니다.
* 오프라인(air-gapped) 모드에서는 리스크 수준이 가져온 취약점 정의를 반영하며, 정의 기준일은 [스캔 히스토리](Scan-History.md)와 시큐리티 센터 페이지에 표시됩니다. 서로 다른 정의 기준일로 분석된 스캔을 비교하면 의존성 트리가 그대로여도 새로운 위협이 나타날 수 있습니다.
