# ユーザーガイド

このページでは OsWL Web ダッシュボードの日常的な使い方を説明します。

表示されるのは自分が**メンバー**であるプロジェクトのみです（**システム管理者**を除く）。プロジェクト内でできることは **ロールテンプレート**（Admin / Developer / Viewer）によって決まります。[権限レイヤー](Authorization-Layers.md)を参照してください。

---

## プロジェクトダッシュボード（`/projects`）

プロジェクトダッシュボードはログイン後の最初の画面です。すべてのアクティブなプロジェクトがカード形式で表示されます。

### プロジェクトカード

各カードには次の情報が表示されます:

| 項目 | 説明 |
|---|---|
| **名前** | プロジェクトの表示名 |
| **バージョン** | 最新スキャンのバージョン文字列 |
| **VCS バッジ** | VCS からインポートされた場合、GitHub / GitLab / Bitbucket のアイコン |
| **ブランチ** | 最後にインポートされたブランチ |
| **最終スキャン** | 直近の完了スキャンからの相対時刻 |
| **リスクバッジ** | CRITICAL / HIGH / MEDIUM / LOW の CVE 件数 |
| **ライセンスバッジ** | 最も悪いライセンス状態（Restricted / Caution / Permitted / Unknown） |

### プロジェクト操作

プロジェクトカードをクリックすると**セキュリティセンター**が開きます。
カードのケバブメニュー（⋮）から次の操作ができます:

* **詳細を見る** — セキュリティセンター
* **ライセンス分析** — ライセンスリスクページ
* **リスクトレンド** — 過去の推移グラフ
* **スキャン履歴** — すべてのスキャンの一覧
* **ゴミ箱へ移動** — プロジェクトのソフトデリート

---

## プロジェクトの作成

プロジェクトを登録する方法は 2 つあります:

1. **Quick Import** — VCS アカウントを接続し、リポジトリ／ブランチを選択します。[Quick Import](Quick-Import.md)を参照してください。
2. **CLI プッシュ** — API キーでプロジェクトを作成し、ビルドパイプラインからスキャンペイロードを送信します。[CLI 連携](CLI-Integration.md)を参照してください。

---

## ゴミ箱

削除されたプロジェクトは**ゴミ箱**セクション（プロジェクト一覧の下部）に入ります。

| 操作 | 説明 |
|---|---|
| **復元** | プロジェクトをアクティブな状態に戻す |
| **完全削除** | すべてのデータ（スキャン、CVE など）を復元不能な形で削除 |
| **選択項目を復元** | 複数プロジェクトの一括復元 |
| **ゴミ箱を空にする** | ゴミ箱内のすべてのプロジェクトを完全削除 |

## プロジェクト内の移動

プロジェクトに入ると、サイドバーから次の画面にアクセスできます:

| セクション | URL パターン | 説明 |
|---|---|---|
| セキュリティセンター | `/projects/{id}/security-center` | CVE 一覧とステータス管理 |
| ライセンス分析 | `/projects/{id}/license` | 依存関係のライセンスコンプライアンス |
| リスクトレンド | `/projects/{id}/risk-trend` | 過去のリスク推移グラフ |
| バージョン比較 | `/projects/{id}/version-diff` | 2 回のスキャンを比較 |
| スキャン履歴 | `/projects/{id}/scan-history` | 過去のすべてのスキャン |
| CLI / API キー | 設定 → CLI タブ | プロジェクト API キーの管理 |

## コンポーネント詳細

セキュリティセンターまたはライセンスビューでコンポーネント（ライブラリ）をクリックすると、**コンポーネント詳細**パネルが開きます。

表示内容:

* 完全名、バージョン、エコシステム
* deps.dev のアップストリームプロジェクトレコードから取得した**プロジェクト説明**、ホームページ、ソースリポジトリへのリンク — OpenSSF Scorecard を取得する際にすでに呼び出している API をそのまま使うため、追加コストなしでエンリッチメント時に埋められます
* CVSS スコア・説明・修正バージョンを含む CVE 一覧 — 上部のライセンス／バージョンバッジとは視覚的に区切られた**セキュリティ課題（Security Issues）**見出しの下にグループ化されます
* ライセンス名とコンプライアンス状態
* AI 生成のライセンスリスク要約（AI が設定されている場合）
* パッチ適用可否（Patchable / Non-Patchable / Unknown）
* 最新の利用可能バージョンと非推奨通知（deps.dev から取得）
* 依存関係パス（コンポーネントがどのように取り込まれているか）

上流に公開された説明がないパッケージについては、何も表示しない代わりにその旨を明示し、ソースリポジトリへのリンクを案内します。
