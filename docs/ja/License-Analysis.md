# ライセンス分析

ライセンス分析ページでは、最新スキャンで検出されたオープンソースライセンスをコンポーネント単位で確認でき、ポリシーに反するものにフラグを立てます。

URL: `/projects/{id}/license`

---

## ライセンスデータの収集方法

OsWL は、スキャンされた各ライブラリについて **deps.dev**（Google の Open Source Insights API）に問い合わせ、SPDX ライセンス式を取得します。これをグローバルなライセンスポリシーと照合してコンプライアンス状態を判定します。

---

## ライセンス状態

各コンポーネントには次の 4 つのライセンス状態のいずれかが割り当てられます:

| 状態 | 意味 | バッジの色 |
|---|---|---|
| **PERMITTED** | ポリシーにより明示的に許可されている | 緑 |
| **CAUTION** | レビューが必要（例: 弱いコピーレフト） | 黄 |
| **RESTRICTED** | 非互換としてフラグが立てられている（例: プロプライエタリコードでの強いコピーレフト） | 赤 |
| **UNKNOWN** | SPDX 識別子が未取得、または未認識 | 灰 |

プロジェクトダッシュボードに表示される全体のライセンスバッジは、すべてのコンポーネントの中で**最も悪い**状態を反映します。

---

## ライセンスポリシー

ライセンスポリシーは、SPDX 識別子を状態にマッピングした一覧です。システム管理者と `LICENSE_POLICY_MANAGE` 権限を持つユーザーがポリシー項目を管理できます。

### ポリシー項目の編集

1. 任意のプロジェクトのライセンス分析ページを開きます。
2. **ポリシーを管理**をクリックします（`LICENSE_POLICY_MANAGE` が必要）。
3. SPDX ↔ 状態のマッピングを追加・編集・削除します。

ポリシー項目は**すべての**プロジェクトに横断的にグローバル適用されます。

### 一般的な SPDX 識別子

| SPDX ID | ライセンス名 | 一般的なポリシー |
|---|---|---|
| `MIT` | MIT License | PERMITTED |
| `Apache-2.0` | Apache License 2.0 | PERMITTED |
| `BSD-2-Clause` | BSD 2-Clause | PERMITTED |
| `BSD-3-Clause` | BSD 3-Clause | PERMITTED |
| `ISC` | ISC License | PERMITTED |
| `LGPL-2.1-only` | GNU LGPL 2.1 | CAUTION |
| `LGPL-3.0-only` | GNU LGPL 3.0 | CAUTION |
| `MPL-2.0` | Mozilla Public License 2.0 | CAUTION |
| `GPL-2.0-only` | GNU GPL 2.0 | RESTRICTED |
| `GPL-3.0-only` | GNU GPL 3.0 | RESTRICTED |
| `AGPL-3.0-only` | GNU AGPL 3.0 | RESTRICTED |
| `SSPL-1.0` | Server Side Public License | RESTRICTED |

## フィルタリング

フィルターバーを使ってライセンスビューを次の条件で絞り込めます:

* **状態** — PERMITTED / CAUTION / RESTRICTED / UNKNOWN
* **エコシステム** — MAVEN / NPM / PYPI など
* **検索** — コンポーネント名と SPDX 識別子にまたがるフリーテキスト検索

---

## AI ライセンスインサイト

AI プロバイダーが設定されている場合、各完了スキャンで次が生成されます:

* **ライセンスリスクトレンドインサイト** — 前回スキャンとのライセンスコンプライアンス比較の要約。
* **ライブラリ別 AI 要約** — コンポーネント詳細パネルに表示される一文のコンプライアンスリスク説明。

どちらもプロジェクトの[デプロイメントプロファイル](Glossary.md)を踏まえて生成されます — 同じライセンスでも、社内専用ツール、ネットワークサービス、顧客に配布されるソフトウェアでは発生する義務が異なるため、要約はライセンス系統の一般的な説明ではなく、その文脈で実際に発生する義務を明示します。

---

## バージョン状態の把握

ライセンス分析ページでは、deps.dev からの追加の 2 つのシグナルも表示されます:

| シグナル | 説明 |
|---|---|
| **最新でない** | より新しい安定版が存在 — アップグレードを検討 |
| **非推奨** | パッケージバージョンが公式に非推奨とされている。非推奨理由が表示される |

これらのシグナルは情報提供のみで、ライセンス状態には影響しません。

## レポートのエクスポート

**`LICENSE_EXPORT`**（またはシステム管理者）権限を持つユーザーは次をダウンロードできます:

* **NOTICE** ファイル — 配布用の著作権表示テキスト
* **SPDX SBOM** — 機械判読可能な部品構成表

エクスポートには権限に加えて**プロジェクトメンバーシップ**も必要です。[権限レイヤー](Authorization-Layers.md)を参照してください。
