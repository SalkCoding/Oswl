Model parameters

Temperature and token limits for LLM calls. Leave blank to use template defaults.
Temperature

Lower means more repeatable, factual output; higher means more varied wording. Triage notes read best at 0.1–0.3 (0–2).

Not used by Anthropic — current Claude models reject a temperature setting, so response style is steered by the prompt instead.

Max tokens

Ceiling on the length of one AI response (256–8192). Too low truncates batch results mid-JSON and the whole batch is discarded; 1200 suits the default templates.

Daily API cap

0 = unlimited. When exceeded, AI enrichment is skipped until the next day.
